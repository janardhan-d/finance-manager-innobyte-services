# Personal Finance Manager

Simple personal finance manager with CLI and Tkinter GUI.

Features:
- Register / Login
- Add / View / Edit / Delete transactions
- Budgets with alerts and progress bars
- Monthly / Yearly reports and dashboard charts
- Profile with photo upload

Run the GUI:

```powershell
python gui.py
```

Run tests:

```powershell
python -m unittest discover -s tests
```

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```
